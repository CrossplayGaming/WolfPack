# UZDoom engine goes here

WolfPack runs on the UZDoom engine (GPL). This folder must contain
`uzdoom.exe` and its support files.

**Easiest**: run `SETUP.bat` in the folder above — it offers to
download the latest official release into this folder automatically.

**Manual**: download the Windows zip from
https://github.com/UZDoom/UZDoom/releases and extract it here so that
`engine/uzdoom.exe` exists.

The build brands the engine's launch art and icon with WolfPack; a
pristine backup is kept as `uzdoom.exe.orig`.
