# Put your Wolfenstein 3D game data here

WolfPack builds the game from **your own copy** of Wolfenstein 3D.
Copy these files from your install into this folder:

    AUDIOHED.WL6  AUDIOT.WL6  GAMEMAPS.WL6  MAPHEAD.WL6
    VGADICT.WL6   VGAGRAPH.WL6  VGAHEAD.WL6  VSWAP.WL6

Where to find them:

- **Steam**: `steamapps/common/Wolfenstein 3D/base/` — if you have the
  Steam version installed, you can even skip this folder entirely; the
  build finds it automatically.
- **GOG / original**: the game's install directory.

The full registered version (WL6 files) is required. No game data is
ever committed to or distributed with this repository.
